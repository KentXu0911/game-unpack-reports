# L39 失败重试与续关报价

来源是既有解包审计中的受控实机记录，本次仅整理与引用，没有重做实验。输入路径与 SHA-256 见 provenance.json；l39-offers.csv 为原汇总 CSV 的完整副本，不发布原始账号日志。

## 条件与观察

原始开场步数参照为 23；为制造受控失败，临时将 moves 强制为 1。8 个样本包含 Start 与 Restart，没有购买续关。弹窗价格始终 900 金币，展示步数依次为 5、10、15、20、25、30、35、35。

展示步数 = EgoManager 套餐基础步数（始终 5）+ EgoExtraMovesHelper 附加步数（0、5、10、15、20、25、30、30）。记录中的 Ego count 与 TryCount 有实验前状态，样本序号不是从新账号第一次失败起算。

## 能说明什么

所测失败重试序列中，付费续关商品同价加量。没有购买，所以不证明支付后实际到账，也不能验证同局第 2–5 档商品。不能据此推断自然连败的统一触发次数、所有账号都会加量、下一局免费增加初始步数，或 DynaDiff／Easy-Hard 阈值表驱动了这项变化。
