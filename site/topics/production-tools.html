分析提炼

分析层
包内没有可读的关卡生产工程。14,991 份 TextAsset 里 14,864 份是二进制，只有 51 份 JSON、39 份文本、37 份半文本；源码文件名记录表除了表头没有任何行。依据：TextAsset 分类统计依据：原生产工具的检索结果
14,500 份关卡以数字 ID 命名。名称前缀统计里纯数字 ID 有 14,500 个，对应逐关二进制；其余前缀分别是 story-（261）、reactivation-（90）、kw（17）、tutorial（4）、segmentedladder（4）、royal（3）。依据：TextAsset 名称前缀kw 与 tutorial 是桌游玩法的关卡模板，不是三消关卡编辑器。
名字像工具的类都不是三消生产工具。PuzzleBoardGenerator 属于外围拼图玩法 PuzzleBreak；LevelLoadValidationHelper 做的是存档 checksum 校验，不是关卡质量验收。依据：原生产工具的检索结果
自建工具的可用输入是齐的。关卡字段清单、289 个模板族、逐关成品与运行约束都能读，足够做一个自建编辑器与校验器。依据：原生产工具的检索结果但自建工具需要自己定义操作、求解策略与质量指标，它不会因为数据齐就等同于原团队的工具。
反推不出设计过程。成品关卡可以读出结论，读出的是“结果长什么样”，不是“团队怎样筛出这一关”。依据：原生产工具的检索结果
