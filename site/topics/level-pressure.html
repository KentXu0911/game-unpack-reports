拆包事实：模板族与机制节奏

事实层

模板指纹由关卡配置里实际启用的字段组合生成，同指纹即同字段组合；机制比例表按 1,000 关分桶，逐关计算后再取段内占比。

分析提炼

分析层
近六成关卡共用同一个基础模板。启用 34 个字段的模板 74cedee671a2 覆盖 8,913 关，分布在关卡 1–13,400；第二大的模板只有 970 关。依据：关卡模板族（按启用字段组合去重）289 个模板族里，启用字段数集中在 33–38 个。依据：启用字段数分布
推断：关卡主要由少量模板加不同内容参数拼出来，而不是每关独立配置。
前期机制几乎不变，变化集中在最后两段。第 1–12 段的六个字段占比都在小幅摆动；首末差异表显示胶囊、魔法灯、金属板从 99%、83%、99% 掉到 3%、0%、17%，保龄球架、调色器、成对物从 0%、13%、17% 升到 97%、99%、83%。依据：按 1,000 关分桶：变化最大的 6 个机制字段依据：首段与末段差异明显的字段
末段关卡只落在 18 个模板上。前 13 段的每 1,000 关有 58–97 个不同模板，13,000–13,999 段升到 154 个，最后一段（14,000–14,500）只有 18 个，其中一个模板占 70%。依据：每 1,000 关的模板构成这也是上面那张表末两行数值跳变的主要背景。
这套统计描述的是配置，不是难度或体验。表格给的是“这一关启用了哪些机制字段”，与玩家胜负、通关时间无关；下方压力公式里的权重由研究者定义，未用真实玩家结果拟合。依据：按 1,000 关分桶：变化最大的 6 个机制字段

配置难度曲线：步数与多目标怎样变化

前500关平均给25.8步，最后500关平均给21.9步；随着进度推进，玩家要在更少的步数里同时处理更多目标。把步数、目标、障碍等七项配置合成压力指标R，前500关均值为42.06，9001–9500关为48.65，最后500关为47.73。

R用于横向比较14,500关的配置结构，权重由研究者设定；它不是官方难度分，也不能换算成玩家胜率。

横轴为关卡区间起点，纵轴为500关平均R。手机上可左右滑动图表，完整数值见下方聚合表。

所有小图纵轴统一为0–1。箭头对比首、末500关均值，曲线保留中间波动。

主要上升：步数更紧、目标种类更多。没有持续上升：已统计的障碍单位负担和目标总量。颜色池基本稳定；按物体层的非零格数计算，后期空洞代理值更低。结合这七项配置，后期的变化主要是同时处理的目标更多、步数预算更紧。

配置压力怎样计算

R = 100 x (
  0.24 x obstacle   + 0.22 x move
  + 0.22 x target     + 0.12 x multiGoal
  + 0.08 x topology   + 0.06 x color
  + 0.06 x predefined
)
轴归一化到 0-1权重
障碍单位负担obstacleCells / cells24%
步数紧张(40 - moves) / 25，截断22%
目标总量targetUnits / (cells x 1.5)，截断22%
目标种类(goalCount - 1) / 3，截断12%
棋盘空洞1 - nonzeroItems / cells8%
颜色池((colorPool or 4) - 3) / 2，截断6%
预定补棋predefined / cells6%
证据边界：七轴都截断到0–1；权重与归一化阈值由分析者设定。颜色池字段为空的18关按原计算脚本使用4色回退，逐关复算误差不超过0.005分（CSV保留两位小数）。障碍轴累加已纳入索引的格子层与箱型／橱柜单位，并非全部98个物体模型的受击成本，也不是去重后的棋盘覆盖面积。棋盘空洞轴仅以非零Items作代理；预定队列长度也不等于实际帮扶力度。这个分数没有用玩家胜率校准。

人工／实机能做到什么，解包增加什么

人工／实机：能从通关记录和录像归纳难点、障碍首现与尾号节奏；样本足够也能画难度曲线，但受覆盖范围和玩家水平影响。

解包增量：可按同一口径批量比较14,500关的步数、目标、层数和颜色池，挑选需实测的异常关。配置压力模型是研究归纳，不是官方难度或玩家胜率。
