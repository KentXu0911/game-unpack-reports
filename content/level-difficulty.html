配置难度曲线：步数与多目标怎样变化

前500关平均给25.8步，最后500关平均给21.9步；随着进度推进，玩家要在更少的步数里同时处理更多目标。把步数、目标、障碍等七项配置合成压力指标R，前500关均值为42.06，9001–9500关为48.65，最后500关为47.73。

R用于横向比较14,500关的配置结构，权重由研究者设定；它不是官方难度分，也不能换算成玩家胜率。

拆开七轴，真正抬压的是哪些东西

主要上升：步数更紧、目标种类更多。没有持续上升：已统计的障碍单位负担和目标总量。颜色池基本稳定；按物体层的非零格数计算，后期空洞代理值更低。结合这七项配置，后期的变化主要是同时处理的目标更多、步数预算更紧。

配置压力怎样计算

R = 100 x (
  0.24 x obstacle   + 0.22 x move
  + 0.22 x target     + 0.12 x multiGoal
  + 0.08 x topology   + 0.06 x color
  + 0.06 x predefined
)
轴归一化到 0-1权重
障碍单位负担obstacleCells / cells24%
步数紧张(40 - moves) / 25，截断22%
目标总量targetUnits / (cells x 1.5)，截断22%
目标种类(goalCount - 1) / 3，截断12%
棋盘空洞1 - nonzeroItems / cells8%
颜色池((colorPool or 4) - 3) / 2，截断6%
预定补棋predefined / cells6%
证据边界：七轴都截断到0–1；权重与归一化阈值由分析者设定。颜色池字段为空的18关按原计算脚本使用4色回退，逐关复算误差不超过0.005分（CSV保留两位小数）。障碍轴累加已纳入索引的格子层与箱型／橱柜单位，并非全部98个物体模型的受击成本，也不是去重后的棋盘覆盖面积。棋盘空洞轴仅以非零Items作代理；预定队列长度也不等于实际帮扶力度。这个分数没有用玩家胜率校准。
