初始棋盘由关卡模板和开局选色共同决定

关卡文件规定棋盘的形状、障碍位置、目标和初始步数。普通棋子的颜色则要分开看：有些格子写死颜色，有些格子只规定可选颜色，进入关卡后才确定最终配色。因此，同一关可以保留相同的布局，每次开局却有不同的消除机会。

开局随机格的候选颜色来自关卡的 LevelSet，和补棋使用的是同一套配置来源。区别在于：开局选色还会检查邻居，排除部分会直接形成三连或同色 2×2 方块的颜色。

下方直接展开四个真实关卡的配置图，可以逐格对照棋子、障碍和草地层；随机格显示候选池标记，不把它画成固定颜色。

开局棋子的颜色是怎么确定的？

1. 先按模板，确定每个格子怎样选色

格子类型实际含义
固定颜色例如模板直接写“红色”，普通随机填色时就保留红色。存在额外替色规则的关卡需单独检查。
候选池：Set1／Set2／Set3分别指向关卡 LevelSet 数组中的第 1、2、3 个池。开局先读取对应池允许的颜色，再检查邻居并选色。
同色组：Match1／Match2／Match3同组格子共用本次选出的颜色。例如三个 Match1 格子这次都为红色，下次可能都为蓝色；这些格子不一定相邻。

2. 同一个颜色池，开局多一道邻居检查

例如，某个随机格使用的 LevelSet 包含红、黄、蓝、绿。开局并不是直接从四色中抽一个：它先看周围已经确定的棋子，去掉部分会直接形成消除形状的颜色，再从剩余颜色中抽取。

示意：某格左边连续两颗都是红棋，如果它再选红色，就会组成横向三连。这次选色会排除红色；若没有其他排除条件，就从黄、蓝、绿中选。同样，若它会补齐代码检查的同色 2×2 方块，也会排除对应颜色。

环节候选颜色从哪里来怎样选
开局的 Set 随机格格子标记指定的 LevelSet提取颜色集合，结合邻居排除部分颜色，再随机选择；这里不等同于补棋按元素权重抽取。
普通补棋补入规则选中的 LevelSet在已核查的第 13479 关普通分支中，按可用元素权重抽取，没有这道相同的开局排除检查，可以直接形成消除和连锁。

第 13479 关只有一套 Set1，开局随机格和普通补棋都从其中的红、黄、蓝、绿取色。多 Set 关卡则要看格子指定哪个池、补入规则选中哪个池；共用配置来源，不代表每次都用同一个池。

这道检查针对开局的随机格选色，不能据此保证所有开局都没有三连。固定颜色、Match 同色分组和其他特殊规则需分别处理；补棋的其他分支见补棋算法。

3. 换 seed 后，仍按这些规则重新选色

seed 可以理解为本局随机数序列的起点。确定 seed、调用顺序和棋盘状态后，选色结果也就确定了。开局选色与普通补棋共用 LevelRandomManager.DifficultyNext 提供的随机数流：开局先取用，之后补棋接着取用，但两者筛选候选颜色的规则不同。

重试换了 seed，随机格和同色组就可能选出不同的颜色。变化既可能是某组一起换色，也可能是各个随机格重新搭配。所以，不能把所有重试变化都理解成“整盘统一换了颜色”。

事实层

关卡文件给出布局模板、初始步数、目标类型及数量、棋子与障碍参数，14,500 份与修复集逐字节一致。下表从逐关统计表与补棋汇总表直接计数。

分析提炼

分析层
标准棋盘是 9×11。10,372 关（71.5%）是 9×11，其次 9×10 占 11.5%、8×11 占 6.6%。复刻时先做好 9×11，覆盖面最大。
高棋盘就是多棋盘关。height ≥ 20 的 693 关与“goals 里出现第 2 块及以上棋盘”的 693 关完全是同一批：2 块棋盘 656 关、3 块 37 关。多块棋盘在关卡文件里是竖向叠放的一张大表，切换规则见棋盘状态机。
目标要按棋盘号拆开读。goals 每条是“目标ID:数量:标志位:棋盘号”，多棋盘关每块棋盘各登记一条，数量可为 0，所以 goal_count 最大到 30。按“数量 > 0 的不同目标 ID”计，每关 3–4 个目标的有 13,509 关。
补棋几乎只用一套配置。13,884 关（95.8%）只有 1 个补棋 set，2 个以上的只有 616 关。1,736 关带预定义补棋队列，开局前几颗补棋是写死的。补棋怎样在多个 set 之间选，见补棋算法。
步数集中在 24 左右。步数 15–40，中位数 24、均值 24.17。步数随关卡号的变化与配置压力模型，见关卡压力、尾号与教学节奏。
格子层障碍有 17 种字段。FTiledCell 声明了草地、蜂蜜、窗帘、锁链、屋顶、果冻等 17 个字段，与棋子层物体分开存放；7,680 关至少有 1 个障碍格。两层的编号不能混用，见代码字典。
