原算法对应的计算步骤

以下为SelectSmartRocket及横纵评分函数的可读伪代码。它决定指定生成格的火箭方向；不移动生成位置，不遍历未来几手。横向与纵向分别使用对应的攻击策略取分，不必假设同一格对两种攻击贡献完全相同。

horizontal = 生成格所在行各格.GetScore(横向火箭策略)之和
vertical   = 生成格所在列各格.GetScore(纵向火箭策略)之和

if horizontal > vertical: return 30 // 横向火箭
if vertical > horizontal: return 20 // 纵向火箭
return levelRandom.Next(0, 2) == 1 ? 20 : 30

例子：假设按对应策略算出的横向贡献为“0、4、0、3、0”，总分7；纵向为“2、0、0、1、2”，总分5，就返回横向火箭30。把纵向总分改为8，才返回20；两边都是7时进入随机。示意贡献值只用于算清流程，真实物体仍走各自评分与状态规则。

横函数从该行x=0的格子沿右邻居累加；纵函数从该列y=0的格子沿上邻居累加。原指令中两次GetScore的策略参数分别为2和1。候选是否受覆盖物或机关修正，发生在评分链中；数障碍数量不等于执行这段算法。

静态证据：SelectSmartRocket 0x20EDA34、CalculateHorizontalRocketScore 0x20EDAF4、CalculateVerticalRocketScore 0x20EDB94。查看原字节快照与方法清单。代码比较已经确认，完整物体评分与所有生成入口的适用范围仍需逐项核对。
